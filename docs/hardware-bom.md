## 三、成本敏感性分析

### 1. 哪些是「必须」成本（不能省）

- **LD6002**（80 元）：核心呼吸感知元件，无替代
- **LD2410B**（28 元）：人体存在感知核心
- **STM32F103**（18 元）：算力底座
- **ESP8266**（10 元）：上云链路

合计：136 元，占比 72%

### 2. 哪些可以「优化」

| 优化方向 | 替代方案 | 可省 | 代价 |
| --- | --- | --- | --- |
| 自绘 PCB → 厂商模块 | 不用 STM32 最小板，直接画 | -5 元 | 增加 PCB 复杂度 |
| OLED → LED 灯阵 | 取消显示屏 | -10 元 | 失去本地可视化 |
| 外壳 → 不做 | 裸板交付 | -10 元 | 工程完成度低 |
| LD6002 → 仅 LD2410B | 去掉呼吸功能 | -80 元 | **功能砍半** |

### 3. 量产场景的成本预估

如果做 1000 套量产：

| 物料 | 单件采购价 | 量产价（估算） |
| --- | --- | --- |
| LD6002 | 80 | 55–60（直接对接厂商代理） |
| LD2410B | 28 | 18–22 |
| STM32F103 | 18 | 8 (芯片+自绘板) |
| ESP8266 | 10 | 6 |
| 其他 | 52 | 35 (规模化采购) |
| **合计** | **188** | **~125** |

降本空间约 33%，量产化对成本控制非常有利。

## 四、成本与功能的对照

每一块钱花在哪：

```
1 元呼吸雷达 ────→ 0.5 bpm 检测精度
1 元存在雷达 ────→ 4–5 m 检测范围
1 元主控    ────→ 72 MHz 算力 + 20 KB RAM
1 元 Wi-Fi  ────→ 全屋远程监控
1 元 OLED   ────→ 1 个本地交互入口
1 元电源    ────→ 12 dB 信噪比提升
```

## 六、采购建议

> 📷 **建议截图位置**：实物照片、PCB 板照片、各模组实物图，放在 `docs/images/bom/` 下。

### 推荐采购渠道

| 物料 | 推荐渠道 | 理由 |
| --- | --- | --- |
| 毫米波雷达（LD2410B / LD6002） | 海凌科官方店 / 立创商城 | 正品保障、有数据手册 |
| STM32 最小板 | 淘宝 / 立创 | 价格低 |
| ESP8266-01s | 淘宝（带底板） | 焊接方便 |
| OLED / DHT11 | 淘宝 | 模块化 |
| PCB | 嘉立创 | 5 片起、24h 出板 |
| 被动元件 | 立创商城 | 散件 + 套装 |

### 采购避坑提醒

1. **LD6002 务必确认 60GHz 版本**（不要买成 24GHz 的早期版本）
2. **ESP8266-01s 优选 1MB Flash 版本**，老版本 512KB Flash 部分 AT 指令不全
3. **OLED 选 4 针 I2C 版本**，不要买 SPI 版本（接线多 3 根）
4. **DHT11 精度低**，预算允许可换 AHT20 / SHT30（仅 +3–5 元，精度提升明显）

## 七、未来 BOM 优化方向

| 方向 | 改进 | 预估变化 |
| --- | --- | --- |
| 主控升级 | F103 → F411（带 FPU，可跑 FFT） | +5 元 |

| 通信升级 | ESP8266 → ESP32-C3（双核、BLE+Wi-Fi） | +5 元 |
| 温湿度升级 | DHT11 → SHT40（±0.2°C） | +5 元 |

**优化后的高配版** BOM 预估：约 280 元，仍在中高端消费级产品价格区间内。
